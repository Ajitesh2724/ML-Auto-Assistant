# ML-Auto-Assistant

ML Auto Assistant is a modular and intelligent tool designed to automate the complete machine learning workflow — from raw data processing to model evaluation, with integrated AI assistance and automated report generation.

**Features**
-  Automated Data Cleaning
-  Feature Engineering & Selection
-  Data Scaling & Train/Test Splitting
-  Model Training & Prediction
-  Evaluation & Performance Metrics
-  AI Chat Assistant for guidance and insights
-  Automated ML Report Generation
-  Extensible & Modular Pipeline Design

**Workflow**

Raw Data → EDA → Data Cleaning → Feature Engineering → Scaling → Train/Test Split → Model Training → Prediction → Evaluation → Tuning


**Installation**

- git clone https://github.com/Ajitesh2724/ML-Auto-Assistant.git
- cd ML-Auto-Assistant
- pip install -r requirements.txt

**Usage**

- Run the core ML pipeline: _python main.py_
- Launch the interactive UI (with AI Chat + Report): _streamlit run app.py_

**Goal**

 To simplify and accelerate machine learning development by automating repetitive tasks and providing a structured pipeline.
