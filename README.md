# ML-Auto-Assistant

🤖 ML Auto Assistant

ML Auto Assistant is a modular tool that automates the end-to-end machine learning workflow, from data preprocessing to model evaluation.

🚀 Features
Automated Data Cleaning
Feature Engineering & Selection
Data Scaling & Splitting
Model Training & Prediction
Evaluation & Performance Metrics
Extensible ML Pipeline

🧩 Workflow
Raw Data → EDA → Data Cleaning → Feature Engineering → Scaling → Train/Test Split → Model Training → Prediction → Evaluation → Tuning

📂 Project Structure
ml-auto-assistant/
│── data/

│── src/
│   ├── preprocessing/
│   ├── feature_engineering/
│   ├── models/
│   ├── evaluation/
│   └── pipeline/

⚙️ Installation
git clone https://github.com/your-username/ml-auto-assistant.git
cd ml-auto-assistant
pip install -r requirements.txt

▶️ Usage
python main.py

🎯 Goal

To simplify and accelerate machine learning development by automating repetitive tasks and providing a structured pipeline.
